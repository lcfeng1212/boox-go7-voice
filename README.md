# BOOX Go 7 中文語音翻頁

版本 0.5.1｜Android 13｜完全離線

在 BOOX Go 7 上看書時，說「下一頁」或「上一頁」就能翻頁，不用伸手碰螢幕或按鍵。主要為「起點讀書」設計；翻頁方式可選左右滑動、點擊左右兩側或上下滑動，其他閱讀 App 也能用。

---

## 簡介

一般 Android 語音控制方案（例如 Tasker 加 AutoVoice）需要多個付費 App、要連網，設定也繁瑣。本 App 把整套流程做成單一 App：

- **離線辨識**：內建 Vosk 小型中文語音模型，全部在裝置上運算。App 不要求網路權限，聲音不會上傳。
- **只做翻頁**：透過 Android 無障礙服務模擬滑動或點擊。服務設定為不讀取螢幕內容，不會取得其他 App 的文字。
- **針對電子紙**：介面是高對比黑白，狀態文字只在內容變動時才重繪，減少螢幕刷新。

適合躺著看書、吃東西、手上拿著東西，或單純不想一直按的時候。

## 運作原理

```
麥克風 ──▶ Vosk 離線中文辨識 ──▶ 指令比對 ──▶ 無障礙手勢 ──▶ 閱讀 App 翻頁
(前景服務)    (只比對翻頁指令)     (防重複觸發)    (滑動或點擊)
```

1. 「離線聆聽」以前景服務持續收音，通知列會常駐一則通知。
2. 辨識結果只要符合翻頁指令，就交給無障礙服務。
3. 無障礙服務依設定的翻頁方式送出手勢（預設為左右滑動）：
   - 下一頁：從右往左滑。
   - 上一頁：從左往右滑。
4. 兩次翻頁至少間隔約 0.9 秒，避免一句話翻兩頁。

## 安裝與首次設定

1. **安裝 APK**：在 Go 7 上點開下載好的 APK。系統詢問時，允許瀏覽器「安裝未知應用程式」，返回後按「安裝」。若出現 Play 安全防護警告，點「更多詳細資料 → 仍要安裝」。
2. **啟用無障礙服務**：開啟本 App，按「① 開啟無障礙設定」，找到「BOOX 語音翻頁手勢」並啟用。
   - Android 13 若顯示「**受限制的設定**」而無法啟用：到「設定 → 應用程式 → BOOX 中文語音翻頁」的 App 資訊頁，點右上角選單「允許受限制的設定」，再回來啟用。
3. **開始聆聽**：回到本 App，按「② 開始離線聆聽」，允許麥克風權限。第一次會先解壓語音模型，狀態顯示「正在載入離線中文模型」，需要稍等。
4. **確認狀態**：App 畫面顯示「無障礙：已啟用」、「麥克風：運作中」，狀態為「離線聆聽中」，即設定完成。
5. **BOOX 背景設定**：在 BOOX 的 App 最佳化設定中，允許本 App 背景執行、不要凍結，否則鎖屏或切換 App 後可能被系統停止。

## 使用方式

1. 完成上述設定後，切回起點讀書並打開書本。
2. 對著裝置說指令，例如「下一頁」。
3. 要停止時，下拉通知列按「停止」，或回本 App 按「停止聆聽」。

### 指令表

| 動作 | 可說的指令 | 何時執行 |
|---|---|---|
| 下一頁 | 下一頁、左滑 | 辨識到就立刻翻頁 |
| 下一頁 | 下 | 要單獨說，說完才翻頁 |
| 上一頁 | 上一頁、右滑 | 辨識到就立刻翻頁 |
| 上一頁 | 上 | 要單獨說，說完才翻頁 |
| 回到桌面並停止聆聽 | 回到首頁、關閉 | 要單獨說，說完才執行 |

- 「下」「上」只有一個字，「回到首頁」「關閉」會離開 App，所以這四個要整句只有這個指令、說完才算，避免「下班」「關閉燈」之類的話誤觸。
- 「下一頁」「左滑」這類指令為了反應快，辨識到就翻頁；講「下一頁是目錄」「上班了」這種句子時可能會被提早翻頁。身邊常有人說話時，可開啟下方的「完整口令模式」。
- 一口氣連講兩次（例如「下一頁下一頁」）不會觸發，要翻兩頁請分開講。

### 完整口令模式（選用，預設關閉）

勾選後，所有指令都要等你說完整句才判斷，而且整句裡只要夾雜其他話就不執行。

| | 預設（快速） | 完整口令模式 |
|---|---|---|
| 反應 | 辨識到就翻頁 | 說完、停頓後才翻頁 |
| 「下一頁是目錄」這類句子 | 可能誤翻 | 不會翻 |
| 單字「上」「下」 | 較容易接到 | 偶爾漏接 |

在 App 內勾選後立即生效，不必重新開始聆聽。依外部測試報告的合成語音重播（v0.5.0），誤觸從 10/27 降為 0/27，有效指令從 22/24 降為 20/24（少接的兩次都是單字「上」）；真人實際效果無法確認。

### 翻頁方式（所有 App 共用）

| 選項 | 下一頁 | 上一頁 |
|---|---|---|
| 左右滑動（預設） | 往左滑 | 往右滑 |
| 點擊左右兩側 | 點右側 | 點左側 |
| 上下滑動 | 往上滑 | 往下滑 |

在本 App 內切換，立即生效。「左滑」「右滑」口令代表下一頁、上一頁，會依這裡選的方式執行。

### 鎖屏自動暫停

螢幕關閉（BOOX 休眠）時會自動關閉麥克風，語音模型和服務保留；解鎖後自動恢復聆聽，不用重新載入。

### 浮球

啟用無障礙服務後，畫面上會常駐一顆麥克風浮球，在任何 App 上都能直接開關聆聽，不用切回本 App。

| 操作 | 效果 |
|---|---|
| 點一下 | 開始聆聽／停止聆聽 |
| 拖曳 | 移到任意位置，下次開機會記住 |
| 拖到左右邊緣放開 | 收起，只露出一小截 |
| 點收起的浮球 | 展開（不會切換聆聽，避免翻書時誤觸） |
| 長按 5 秒 | 開啟本 App |

| 浮球樣子 | 狀態 |
|---|---|
| 黑底白色麥克風 | 聆聽中 |
| 灰色 | 正在載入語音模型或重新啟動，請稍等 |
| 白底黑框麥克風 | 已停止 |
| 白底寫「重試」 | 麥克風連續 5 次啟動失敗，已自動停止；點一下重新開始 |

- 停止是完全關閉收音，通知也會消失，最省電；再次開啟要等模型載入幾秒。
- 浮球就算停在畫面正中間，也不會擋到語音翻頁，翻頁手勢會自動換位置避開。
- 浮球只在狀態改變時才重繪，減少電子紙刷新。
- 不想看到浮球：在本 App 取消勾選「顯示浮球」。
- 點浮球開始聆聽時，畫面會閃一下，這是正常的。Android 規定麥克風服務只能在 App 畫面可見時啟動，所以會先開一個看不見的畫面、啟動收音後馬上關閉。

### 測試按鈕

App 內的「測試下一頁」、「測試上一頁」會依目前的翻頁方式直接送出一次手勢，用來確認無障礙服務有沒有作用。手勢會作用在當下的畫面上，也就是本 App 自己，所以畫面不會有明顯變化；只要提示「已送出手勢」就代表正常。

## 兩種辨識模式

App 內可勾選「限定指令模式」，預設為開啟。

| | 限定指令模式（預設） | 一般模式 |
|---|---|---|
| 辨識範圍 | 只比對翻頁指令，其他聲音一律視為未知 | 完整中文模型，什麼話都會轉成文字再比對 |
| 誤判 | 較少 | 較多 |
| 耗電／運算量 | 較低 | 較高 |
| 反應速度 | 較快：話還沒講完、辨識穩定時就翻頁 | 較慢：要等講完、停頓後才翻頁 |
| 何時改用 | — | 限定模式聽不到你的指令，或旁人說話也一直誤翻時，切換比較看看 |

切換模式後，要先按「停止聆聽」再重新「開始離線聆聽」才會生效。

## 隱私與權限

| 權限 | 用途 |
|---|---|
| 麥克風（RECORD_AUDIO） | 收音辨識翻頁指令。聲音只在裝置上處理，不會儲存或上傳 |
| 前景服務（FOREGROUND_SERVICE、FOREGROUND_SERVICE_MICROPHONE） | 切到閱讀 App 後仍可持續收音 |
| 通知（POST_NOTIFICATIONS） | 顯示「正在聆聽」常駐通知與停止按鈕 |
| 無障礙服務 | 只用來模擬滑動手勢；設定為不讀取視窗內容（`canRetrieveWindowContent=false`） |

App 不要求網路權限（INTERNET）。每次編譯時，CI 都會自動檢查 APK 的權限清單，確認沒有網路權限。

## 疑難排解

| 狀況 | 可能原因與處理 |
|---|---|
| 按「開始離線聆聽」跳出「請先啟用無障礙手勢」 | 無障礙服務尚未啟用，請先完成設定第 2 步 |
| 無障礙服務無法啟用、顯示「受限制的設定」 | 見設定第 2 步，先在 App 資訊頁允許受限制的設定 |
| 狀態顯示「無障礙手勢未成功」 | 無障礙服務被系統關閉。請到無障礙設定重新啟用 |
| 說了指令沒反應 | 先看 App 狀態是否為「離線聆聽中」；說話距離近一點、語速放慢；仍不行就切換成一般模式比較 |
| 旁人說話或看影片時誤翻頁 | 確認已開啟限定指令模式；仍誤翻則暫停聆聽 |
| 用一陣子後自動停止 | BOOX 背景限制中斷了服務，請完成設定第 5 步。鎖屏只會暫停、解鎖自動恢復 |
| 浮球顯示「重試」 | 麥克風連續啟動失敗，常見原因是其他 App 正在使用麥克風。關掉那個 App 後點浮球重試 |
| 翻頁沒反應但狀態顯示「已送出手勢」 | 這個閱讀 App 不支援目前的翻頁方式，到本 App 換一種翻頁方式 |
| 第一次開始聆聽很久才就緒 | 正在解壓語音模型，只有第一次（以及更新到 0.5.1 後的第一次）會這樣 |
| 模型檔損壞或被刪 | 每次啟動都會檢查模型檔；有缺漏會自動重新解壓，載入失敗也會自動再試一次 |
| 狀態顯示「辨識逾時，正在重新啟動」 | 收音中斷後 App 會自動重啟辨識，通常幾秒內恢復 |

## 已知限制

- 持續收音會增加耗電，不看書時建議停止聆聽。
- 只用聲音翻頁、完全不碰螢幕時，BOOX 是否會自動休眠，尚未在實機上確認。
- 目前只在 Android 13 模擬器做過安裝與啟動測試；語音辨識率與起點讀書的實際翻頁效果，須以 BOOX Go 7 實機為準。

## 開發與編譯

### 專案結構

```

├── MainActivity.java              主畫面：設定步驟、模式切換、狀態顯示
├── OfflineListeningService.java   前景服務：收音、Vosk 辨識、錯誤自動重啟
├── SwipeAccessibilityService.java 無障礙服務：送出左右滑動手勢、承載浮球
├── FloatingBall.java              麥克風浮球：繪製、拖曳、收起、點擊與長按
├── BallLayout.java                浮球位置規則（貼邊、收起、展開）
├── StartListeningActivity.java    看不見的跳板畫面，讓浮球能合法啟動麥克風服務
├── CommandEngine.java             指令清單、快速／整句兩種判斷、文字正規化、防重複觸發
├── GestureGeometry.java           三種翻頁方式的手勢座標，並避開浮球
├── ModelAssets.java               從 APK 取出語音模型（Android 介面）
├── ModelStore.java                解壓模型：同時只一個工作、暫存後換上、檔案清單驗證
├── RestartPolicy.java             辨識失敗時的退避重試，連續 5 次失敗即停止
└── ListeningHealth.java           偵測辨識停止回應
scripts/
├── prepare_model.py               下載官方 Vosk 中文模型並檢查 ZIP 安全性
├── check_grammar_vocab.py         確認每個指令詞都在模型詞彙表內
├── sign_apk.sh                    正式簽章（從舊金鑰輪替到私人金鑰）
└── emulator_smoke.sh              模擬器安裝與啟動測試
tests/                             指令、浮球位置、模型解壓的單元測試
```

### 本機編譯

需要 JDK 17、Android SDK（platform 35、build-tools 35.0.0）、Gradle 8.9。

```bash
bash tests/run_tests.sh                               # 單元測試
python3 scripts/prepare_model.py                      # 下載語音模型
bash tests/run_tests.sh app/src/main/assets/model-cn  # 測試並檢查指令詞彙
gradle assembleDebug                                  # 本機測試用，產出 app/build/outputs/apk/debug/app-debug.apk
```

### 新增指令

1. 在 `CommandEngine.GRAMMAR_PHRASES` 加入辨識用的詞組。要用**簡體、以空格分詞**，而且每個詞都必須在模型詞彙表內。例如「上一页」不是模型裡的詞，要寫成「上 一页」。
2. 在 `CommandEngine.lookup` 加入對應的寫法（以簡體比對；`normalize` 會把繁體轉成簡體），單字或會離開 App 的指令請用整句模式（`isStrict`）。
3. 執行 `bash tests/run_tests.sh app/src/main/assets/model-cn`。詞彙表裡找不到的詞會列為 `MISSING`。

### 自動編譯（GitHub Actions）

每次 push 到 `main` 會自動執行 `.github/workflows/build-apk.yml`：

1. **build**：單元測試 → 下載（或從快取還原）語音模型 → 檢查指令詞彙 → 編譯 release APK → 正式簽章 → 檢查權限與內容 → 上傳 Artifact。
2. **emulator-smoke**：在 Android 13 模擬器安裝 APK、啟動主畫面、確認兩個服務都有宣告，並實際操作浮球（開始／停止聆聽、長按、收起與展開）。
3. **release**：前兩項都通過後，把 APK 發布到固定下載連結。

整個流程約 4 分鐘。

## 版本紀錄

### 0.5.1
- 新增「完整口令模式」（選用，預設關閉）：說完整句、句中沒有其他話才執行。

### 0.4.0
- 新增麥克風浮球：點一下開關聆聽、拖到邊緣收起、點收起的浮球展開、長按 5 秒開啟 App；浮球顏色顯示聆聽、載入、停止三種狀態。
- 語音翻頁的滑動路徑會自動避開浮球。
- App 內新增「顯示浮球」開關。
- 模擬器測試新增：從主畫面點浮球開始與停止聆聽（含確認麥克風權限有效）、長按開啟 App、拖曳收起與展開。

### 0.3.0
- 新增限定指令模式（預設開啟），可在 App 內切換回一般模式。
- 限定模式下，辨識穩定後立即翻頁，不用等講完停頓。
- 修正「小書下一頁／小書上一頁」無法觸發的問題。
- 新增「翻頁」指令；限定模式下，指令前後的未知雜音不再影響比對。
- 狀態文字只在變動時重繪，減少電子紙刷新。
- APK 只保留 arm64 與 x86_64 原生函式庫，大小從約 83 MB 降到約 63 MB。
- CI：模擬器啟用硬體加速、快取語音模型、檢查指令詞彙與權限；整體時間從約 17 分鐘縮短到約 4 分鐘。
